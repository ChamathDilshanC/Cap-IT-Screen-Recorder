# Cap-IT brand package

Midnight (dark) and Arctic (light) brand identity for Cap-IT Screen Recorder, baseline v3.13.1.

| Deliverable | What it is |
|---|---|
| [`Cap-IT-Brand-Book.pdf`](Cap-IT-Brand-Book.pdf) | The editorial brand book (16:9, 68 pages, both themes) |
| [`Cap-IT-Brand-Guidelines.md`](Cap-IT-Brand-Guidelines.md) | Editable specification |
| [`Cap-IT-Brand-Tokens.json`](Cap-IT-Brand-Tokens.json) | Shared tokens: spacing, radius, type, motion, gradients, feature identity, logo hues |
| [`Cap-IT-Dark-Theme.json`](Cap-IT-Dark-Theme.json) · [`Cap-IT-Light-Theme.json`](Cap-IT-Light-Theme.json) | Each theme: `implemented` (shipped values) and `proposed` (Midnight / Arctic tokens with measured contrast) |
| [`avalonia/CapIT.Brand.Proposed.axaml`](avalonia/CapIT.Brand.Proposed.axaml) | Proposed brushes for both themes. **Not referenced by the application** |
| [`Cap-IT-Brand-Assets/`](Cap-IT-Brand-Assets/) | `logo/` · `app-icon/` · `icons/` · `graphics/` · `screenshots/` · `templates/` |
| [`source/`](source/README.md) | HTML, builders, fonts, QA |

Every item is labelled **EXISTING**, **DERIVED**, **PROPOSED** or **CONCEPT**. The application's production UI and the recording pipeline were not modified.
